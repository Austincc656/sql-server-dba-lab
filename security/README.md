# SQL Server Security

This directory documents security-related configuration and exercises in the Microsoft SQL Server DBA lab.

## Configuration Completed

During SQL Server installation, the Database Engine was configured to use **Mixed Mode authentication**, allowing both Windows Authentication and SQL Server Authentication. The Windows Server Administrator account was also added as a SQL Server administrator.

This establishes the foundation for later hands-on work with SQL Server security.

## Upcoming Exercises

- Creating SQL Server logins
- Creating database users
- Server roles and database roles
- `GRANT`, `DENY`, and `REVOKE`
- Principle of least privilege
- Authentication troubleshooting
- Auditing access and permissions

Security exercises will be added progressively as they are completed in the lab.
