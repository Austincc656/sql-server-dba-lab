# SQL Scripts

This directory will contain SQL scripts created and executed as part of the Microsoft SQL Server DBA lab.

The environment is now installed and operational, and SQL Server Management Studio is successfully connected to the SQL Server instance. SQL scripts will be added here as database administration exercises are completed.

## Planned Areas

- Database creation and configuration
- Database inspection and metadata queries
- Tables and relational structures
- Users and permissions
- Backup and restore commands
- Database integrity checks
- Index inspection and maintenance
- Performance and monitoring queries
- SQL Server Agent administration

Only scripts that have actually been implemented and tested in the lab will be documented as completed work.
